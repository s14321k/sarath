Most identical-looking pair — the code looks EXACTLY the same!
Core insight: Strategy = YOU choose the behavior. State = object automatically switches itself when something happens.

// Strategy — client picks
sorter.setStrategy(new BubbleSort()); // explicit choice
sorter.sort(data);

// State — object self-transitions
machine.insertCoin();   // internally: state = HasCoinState
machine.pressButton();  // internally: state = NoCoinState again
Litmus test:
"Who sets the next behavior?"
→ Client code sets it? = Strategy
→ Object sets it on itself after an event? = State

Template Method vs Strategy
Both vary algorithm steps. One uses inheritance, one uses composition.
Core insight: Template locks the skeleton in base class — subclasses fill gaps. Strategy injects the whole algorithm from outside.
